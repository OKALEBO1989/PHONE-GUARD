
# PHONE GUARD

**PHONE GUARD** is a mobile phone security application designed to protect a phone against theft and unauthorized handling.

## Main Features

1. **Automatic Alarm Activation:** The alarm activates automatically when someone steals or tampers with the phone.
2. **Loud Voice Alert:** The application announces:

   "THIS PHONE IS STOLEN FROM THE OWNER.PLEASE CALL.0778044126!"

3. **Continuous Alarm:** The alarm continues until the authorized owner enters the correct security PIN.
4. **Anti-Theft Protection:** Designed to discourage unauthorized handling and theft.
5. **Owner Control:** Only the authorized owner should be able to deactivate the alarm.

## Project Goals

- Improve mobile phone security.
- Discourage phone theft.
- Alert people nearby when unauthorized handling occurs.
- Give phone owners greater control over their devices.
